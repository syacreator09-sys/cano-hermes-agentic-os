# learning-session

Diseñar una sesión breve y acumulativa usando el objetivo, nivel y progreso registrado de Cano.

## Procedure

1. Recuperar el tema, nivel, glosario y último avance confirmado.
2. Elegir un objetivo concreto y explicar solo los conceptos necesarios.
3. Usar ejemplos relacionados con negocios, automatización, contenido o finanzas cuando ayuden.
4. Incluir una comprobación práctica y registrar únicamente aprendizajes confirmados.
5. Solicitar aprobación antes de actualizar un expediente persistente, inscribir cursos o enviar materiales.

## Verification

- Diferenciar hechos, ejemplos e inferencias.
- Corregir errores sin presentar información inventada.
- Mantener continuidad con el glosario existente.
- Confirmar que no se realizó ninguna acción externa sin aprobación.
