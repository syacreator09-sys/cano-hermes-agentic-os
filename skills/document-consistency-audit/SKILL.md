# document-consistency-audit

Revisar una copia de trabajo de documentos para detectar diferencias, errores y riesgos sin modificar originales.

## Procedure

1. Registrar archivos, versiones, periodos y huellas disponibles antes de analizar.
2. Extraer fechas, nombres, referencias, saldos, sumas, periodos y metadatos relevantes.
3. Comparar consistencia interna y entre documentos usando cálculos reproducibles.
4. Separar error confirmado, diferencia visual, dato ausente e hipótesis.
5. Preparar el reporte y solicitar aprobación antes de compartir o exportar una copia redactada.

## Verification

- Conservar evidencia y ubicación exacta de cada hallazgo.
- Recalcular sumas de forma independiente.
- No alterar, reconstruir ni falsificar el documento fuente.
- Confirmar que ninguna copia sensible fue compartida sin aprobación.
