# Identidad de StarHome OS

## Nombre oficial

**StarHome OS**

## Descripción corta

Sistema Operativo Agéntico Autónomo para Cano.

## Significado

- **Star**: visión, guía, expansión, descubrimiento y dirección.
- **Home**: base operativa, memoria, control, pertenencia y continuidad.
- **OS**: capa de coordinación que une agentes, modelos, herramientas, datos, interfaces y políticas.

StarHome OS representa un hogar inteligente para todo el ecosistema agéntico de Cano: un punto central desde el que se organizan proyectos, agentes, memoria, contenido, infraestructura y decisiones.

## Promesa del producto

> Orquesta agentes, memoria, contenido y operaciones desde un solo centro.

## Personalidad

- confiable;
- estratégica;
- tecnológica;
- clara;
- modular;
- poderosa sin ser caótica;
- autónoma, pero supervisada.

## Lenguaje visual

- fondo oscuro azul profundo;
- acentos cian, azul eléctrico y violeta;
- paneles tipo glass UI;
- conexiones luminosas entre agentes;
- núcleo central representado por el Conductor;
- formas hexagonales, orbitales y de red;
- tipografía limpia, técnica y legible.

## Uso del nombre

Usar siempre:

```text
StarHome OS
```

Evitar variaciones como:

```text
Star Home
Starhome
StarHome AI OS
Hermes StarHome
```

El repositorio técnico puede conservar temporalmente el nombre `cano-hermes-agentic-os`, pero la interfaz, documentación de producto y experiencia del usuario deben utilizar **StarHome OS**.
